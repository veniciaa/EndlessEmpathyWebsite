## Project Overview

Endless Empathy is a nonprofit organisation that aims to help and support people.

The main goal for Endless Empathy is to create a comunity that cares for eachother.
The website will provide information about the organisation and its projects and sevices. 
This website will also help people get involved in the community and be made aware about ways to support the non-profit organisation.

## Website Goals and Objectives

The main goals of the website are:
- Provide information about Healing Hands.
- Explain the services provided by the organisation.
- Allow visitors to find contact information.
- Make information easy to find and understand.
- Create a simple and user-friendly website.
